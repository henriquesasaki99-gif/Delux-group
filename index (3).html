Integração fiscal futura

Na versão de produção, o ADM terá o comando Emitir NFC-e somente depois da configuração do estabelecimento fiscal, cadastro tributário, autenticação no servidor e serviço emissor. ETIQUETAS A4 • MÓDULO INDEPENDENTE

Esta área é exclusiva para consultar produtos sem código, registrar códigos de barras e imprimir etiquetas; não apresenta relatórios financeiros.

Folha A4: 4 colunas × 9 linhas = 36 etiquetas. Cada adesivo mede 52,5 mm × 33,0 mm. O conteúdo impresso é centralizado em área de 45 mm × 27 mm para não ultrapassar a linha de corte. Testar escala 100% na folha adesiva física. Etiquetas utilizam Code 39.

Selecione um produto sem código, digite ou gere um código de barras exclusivo e salve. Depois ele ficará disponível na lista de impressão.

Bairros, integridade e cópia de segurança

Bairros

Os bairros são criados pelo ADM conforme a necessidade, sem unidades pré-cadastradas. Somente o ADM pode cadastrar, renomear e excluir bairros. Para proteger o histórico e o estoque, a exclusão só é liberada para lojas sem usuários, produtos vinculados, vendas ou movimentações. Faça backup antes de excluir.

Backup completo

Backup local completo de dados operacionais + contas deste navegador. Agendado para 22:00 quando uma sessão ADM ou Backup estiver aberta. Se não ocorrer, será oferecido um download no próximo acesso do ADM ou Backup. O navegador pode exigir permissão para baixar; não é executado com o navegador fechado e não é backup na nuvem.

Consultar vendas pendentes

A restauração exige confirmação. Faça cópia da base atual antes de substituir.

Central de Backup • Acesso exclusivo

Exportar uma cópia de segurança

Esta conta possui acesso somente para backups. Permite exportação manual e solicita uma cópia diária às 22h enquanto a página estiver aberta. Se não houver registro da tentativa anterior, oferece a cópia no próximo acesso. Futuramente, com Firebase, a central receberá os backups consolidados de todos os bairros e dispositivos. Nenhuma tela de produtos, vendas, custos, relatórios ou restauração é liberada.

Protótipo: o arquivo contém somente os dados e contas deste navegador. O navegador precisa estar aberto às 22h para tentar baixar automaticamente. Não é possível confirmar que o download foi salvo. Produção futura: um agendador na nuvem fará o backup centralizado às 22h, independentemente do navegador, e este login permitirá consultar e baixar as cópias autorizadas. Os arquivos devem ser guardados em local protegido.

Use as setas para escolher em qual posição cada aba aparece no menu administrativo. Os nomes não serão alterados. A ordem do vendedor continuará começando por Metas, depois PDV e Mensagens. A configuração fica salva no navegador e incluída no backup JSON.

Contas e permissões

Criar acesso individual

O perfil Vendedor acessa somente o PDV do bairro. O perfil Backup acessa somente a Central de Backup e solicita cópia local diária às 22h quando a página estiver aberta. Somente o ADM gerencia usuários, relatórios, estoque e configurações.
